# choosing-a-model

`choosing-a-model` picks a model tier and reasoning effort for a job. It names the criteria first (capability, speed, cost, effort), maps the provider's lineup onto four tiers (frontier, flagship, balanced, fast), starts efficiency-first or capability-first, and settles the pick with an eval on the job's own prompts. It also covers pairing a cheap model with a strong one.

The skill names no model, so it stays true as lineups change: the agent reads the provider's model docs to fill in the tiers each time.
